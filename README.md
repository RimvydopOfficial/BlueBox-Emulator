# BlueBox Emulator

BlueBox Emulator is an experimental Windows compatibility and gaming environment for Android.

The project aims to provide a simple Android interface for creating and managing Windows environments, with a long-term focus on Windows applications, games, and Steam.

> ⚠️ **BlueBox is currently in early Alpha development.**
>
> Many features are incomplete or not functional yet. The current releases are development builds intended to show project progress.

## Current Version

**v0.0.1 Alpha**

This is the first public development release of BlueBox Emulator.
